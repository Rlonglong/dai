# D-Track 與 Superset 手冊

這份手冊涵蓋兩套「**有網頁介面、平常要有人去點**」的系統：

| 系統 | 在回答什麼問題 | 誰會用 |
|---|---|---|
| **Dependency-Track** | 我們用的第三方套件有沒有已知弱點？ | 維運人員、開發人員 |
| **Superset** | 資料跑完之後，怎麼看、怎麼給業務單位看？ | 業務單位、開發人員 |

兩套包在同一份手冊，是因為它們的共同點是「**UI 操作為主、不需要改程式碼**」，
使用者重疊，而且都靠 Keycloak SSO 登入。

> ⚠️ **機器位置**：依目前的 compose 設定，
> **Dependency-Track 跑在 VM3**（與 GitLab、Container Registry 同機），
> **Superset 跑在 VM5**（與 Keycloak、nginx 同機）。
> 若正式環境把 D-Track 改到 VM5，請一併更新本手冊與部署手冊 Phase 3。

## 一句話版本

> **D-Track**：每次推程式碼、每季一次，把我們用的套件清單拿去比對弱點資料庫，
> 有 Critical 就讓 pipeline 紅燈、東西上不去。
>
> **Superset**：Dagster 跑完的名單與統計，在這裡變成業務單位看得懂的圖表。
