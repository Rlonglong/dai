# =============================================================================
# rsync 排除清單 —— dagster_workspace → VM4
# =============================================================================
# 用法（見 ci/deploy_rsync.sh）：
#   rsync -a --delete --exclude-from=deploy_exclude.txt \
#         dagster_workspace/ gitlab_runner@VM4:/data/deploy/workspace/dagster_workspace/
#
# 路徑一律相對於「傳輸根目錄」，也就是 dagster_workspace/ 本身。
#
# ★這份清單同時是「刪除保護清單」★
#   rsync 的 --delete 預設**不會**刪掉被 --exclude 排除的檔案（那叫
#   --delete-excluded，我們沒有開）。所以只要列在這裡，VM4 上那份就活得下來。
#   .env 和 profiles.yml 靠的就是這個機制，漏一行 = 部署當下把正式機的帳密洗掉。
#
# repo 根目錄的 docs/、ci/、.gitlab-ci.yml 等等不在傳輸根目錄底下，
# 本來就不會被傳，不需要（也不能）寫在這裡。
# =============================================================================
